# 使用 DevEco Studio 预览器录制交互演示

本项目原有的六个原生鸿蒙业务页面依然保留（Index、Home、Add、Detail、Edit、Settings），正常应用启动入口仍为 Index。

> 如果直接在预览器打开 `Add.ets`，保存可能提示“保存失败”，因为真正的 NoteStore 依赖设备文件系统和页面初始化。请使用下面新增的预览模式，不要在旧的 Add.ets 中重复保存。

## 网吧电脑上的最短操作

1. 下载本仓库最新的 `Code → Download ZIP`，解压到电脑；在 DevEco Studio 中选择「打开项目」，打开包含 `AppScope`、`entry`、`build-profile.json5` 的工程根目录。
2. 打开 `entry/src/main/ets/pages/PreviewDemo.ets`。
3. 点击右侧的 👁 眼睛（Previewer），等待编译预览。**不要点击顶部的绿色三角形**，它会要求真机或模拟器（网吧的 Hyper-V 限制可能导致模拟器不能启动）。
4. 在 PreviewDemo 的登录界面填入 `admin`、`123456`；进入列表后已经有一条示例备忘录。
5. 用录屏软件录制：登录 → 打开示例记录的详情 → 点击编辑并修改、保存 → 返回列表 → 新建一条备忘录并保存 → 通过搜索找到它 → 打开详情、删除 → 进入设置 → 退出登录。
6. 使用 Windows 自带的「截图工具」录屏或其他合法的录屏软件录制 **DevEco Studio 的预览器窗口**，必要时展示左侧 `PreviewDemo.ets` 源代码以说明是原生 ArkUI 预览。

## 作用与限制

- 这个是**鸿蒙 ArkUI 组件的预览演示**，在同一组件内切换六种界面状态，并通过 NoteModel 处理新建、编辑、搜索、删除逻辑。
- 为适应 Previewer，它仅将数据留在组件内存里；**刷新或关闭预览会丢失记录**，不调用文件系统或路由。
- 它不能证明设备上的 HAP 已安装、启动，不能用来冒充真机录屏。
- 真正的原生应用源码与编译工作流未替换；正式运行时仍走 `Index.ets` 及应用存储。
